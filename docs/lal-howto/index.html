如何寄存證信函

選範本 → 產出 → 蓋章 → 回執 → 郵局寄出

1【存證信函範本】作業流程

  1. 挑選以下合適的範本（工具箱內建，或線上產生器）
  2. 複製後到存證信函產生器貼上
  3. 修改內文後按產出（下載 PDF）
  4. 蓋公司大小章
  5. 填寫回執單
  6. 至郵局寄出
打開工具箱產生器 線上產生器（lalg-pro）↗

!注意事項

  • a. 切勿從其他範本中擷取部份內容混在一起；若有多項情況，先與主管討論。
  • b. 收件人地址：租屋處；副本地址：戶籍地。
    僅有收件人：列印 3 份；有收件人＋副本：列印 4 份。
  • c. 寄出後的存證信函與回執，請各地區統一找地方妥善保存，日後需轉交法務。

2【催告流程】什麼叫「完成催告」

所謂完成催告，指「存證信函寄出且收到回執」。

提供法務要做強執的案件，一定要有以下資料檢附，法務才能受理：

  • 1兩封存證信函正本
  • 2兩件存證信函回執
  • 3超過信函送達日起算之期限
  • 4有簽終止協議或其他協議，要再一併檢附
重點

沒有「信函正本＋回執」＝催告未完成，法務無法受理強執

?相關知識（勿踩紅線）

租約未到期前，房東／管理者原則上不可擅自進入已出租房屋帶看、進入屋內，或擅幫房客打包。催收過程請依 SOP（聯繫、面訪貼單、存證信函…），不可跳過程序用強制手段。
