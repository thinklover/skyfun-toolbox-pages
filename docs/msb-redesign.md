# 會議計分中心重做｜設計（A：一頁總表）

## 目標
- 一進頁就能掃完「所有人的分數＋獎金」
- 加減分少步驟、好操作
- 介面直觀，拿掉多餘模式與吵雜提示

## 非目標
- 不改公司登入／權限規則本體（仍：一般人看自己；有權限看全部、可編）
- 不一次大改資料表結構（沿用現有 `msb_*` RPC；權限 SQL 另請人套）
- 不做大卡／批次貼上等進階模式（需要再說）

## 主畫面（唯一首頁）
一張表，預設顯示當月：

| 部別 | 姓名 | 分數 | 獎金 | 操作 |
|------|------|------|------|------|
| … | … | 數字或 — | 金額／未發放 | ＋ − |

- 表頭切換：**系統會議**｜**月會主管**
- 月份選擇器（預設本月）；搜尋姓名／部別
- 有權限：分數、獎金可點進去改（小窗或列內編輯擇一，實作採「點格子開小窗」較不易誤觸）
- 一般員工：只看自己那一列（或自己卡片），看不到別人

## 加減分
- 列上 **＋／−** → 小窗：選專案／項目、分數、備註、日期 → 存檔
- 頂部保留「新增加減分」（可不先選人）
- 「加減分紀錄」改成次要頁：用表列出期間紀錄，可刪（有權限）

## 設定（有權限）
人員、專案維護收到「設定」；對帳／補部別仍可用，但主畫面不堆一堆紅字——未填部別者歸「未填部別」分組，安靜顯示。

## 拿掉
- 大卡檢視、輸入分數／獎金獨立模式、批次貼上入口
- 側欄過重視覺；改成頂部簡導覽（儀表板｜紀錄｜設定）或極簡側欄
- 「權限 SQL 未套用」改成單行淡提示，不擋主表

## 成功長相
主管打開頁面：先看到全員分數／獎金表；要加減分就按該列 ＋／−，兩步內完成。
